# NEBULA · 蝴蝶

一只发光的蝴蝶，在嵌套的光框、回声光廊和玻璃之间穿行。整个场景都是用 Three.js 和 GLSL 实时渲染的 3D 空间，不是视频。

画面按参考视频的五个镜头循环播放，每个镜头之间会短暂暗场切换：

1. 标本光框：嵌套的方形光框，中央是发光的蝴蝶。
2. 回声光廊：蝴蝶的残影一路延伸到十字光源。
3. 回返：大片失焦的蝴蝶从镜头前掠过。
4. 蝴蝶长廊：墙面布满蝴蝶剪影，残影一直延伸到远处的光。
5. 玻璃栖息：蝴蝶停在缓缓转动的玻璃板上，合着翅膀，偶尔轻轻打开。

## 交互

- 移动鼠标：镜头轻微视差，蝴蝶会看向你的方向。
- 拖动：小幅环绕观察，松手后慢慢回位。
- 滚轮或双指：拉近、拉远。
- 轻触蝴蝶：它会扑扇一下翅膀，洒下光尘。
- 双击或按 F：全屏。空格：暂停。左右方向键：切换镜头。
