# NEBULA · 蝴蝶走马灯

光框组成一条长廊，每个光框里都有一只**静止**的蝴蝶。76 个光框是一个循环，对应画面上的 `FRAME 01 / 76`。每一帧里的蝴蝶姿态都略有不同。光框快速向后飞逝时，这些静止的蝴蝶连起来，看起来就像在飞，原理和手翻书、走马灯一样。

## 玩法

- **选择场景**：标本光框 / 回声光廊 / 失焦回返 / 蝴蝶长廊 / 玻璃栖息，或者打开「连播」自动轮换。
- **暂停 / 继续**：暂停后，光框会停在当前那一帧。
- **抽出蝴蝶**：点击任意一只蝴蝶（播放中点击也会自动暂停），它会飞出光框，落到你面前的玻璃上。
  - 拖动画面可以转动它，滚轮可以缩放，也可以切换正面、侧面、背面、俯视。
  - 可以调整翅膀开合角度、光晕、大小和色调，还可以写一句话留给它。
  - 点「记录这只蝴蝶」保存下来（会附带缩略图）。点「放回光框」，它会飞回原来的光框。
- **继续**：被抽出的蝴蝶飞回光框后，长廊继续前进。被记录过的光框会亮起金色边，经过时一眼就能认出。
- **倒放**：按住「按住倒放」按钮（或 ← 键），长廊会倒着流动。
- **回到记录**：在「记录」里勾选一只或几只蝴蝶，再点倒放。长廊会倒带，依次回到每一只当时所在的那一帧，把它重新抽出来，并恢复你记录时的样子。

记录和播放进度会保存在浏览器本地，重新打开网页还能接着看。

快捷键：空格 暂停/继续 · ← 按住倒放 · Enter 记录 · Esc 放回 · R 记录列表 · 1–5 场景 · 6 连播 · F 全屏
