# NEBULA · 沉浸式 3D 光影粒子艺术

一个可以直接在浏览器里运行的实时 3D 互动艺术网站，用 Three.js、WebGL 和 GLSL 着色器实现。主要内容：

- **展示模式**：发光 3D 蝴蝶、时空隧道、粒子宇宙、能量爆发、极光、蝴蝶重生，共 6 种视觉模式和 10 个场景预设。
- **3D 创作工作室**：可以自由修改蝴蝶、粒子、飞行轨迹、特效、场景和光影，并把作品保存在浏览器里。

整个项目是**纯静态网站**：不需要构建，不需要服务器，也不需要 npm。Three.js 已经放在 `vendor/` 文件夹里，不依赖外部 CDN。

---

## 发布到网上（GitHub Pages，免费，大约 2 分钟）

1. 在 GitHub 新建一个**公开**仓库，比如 `nebula`。
2. 解压 ZIP，把里面的**所有文件和文件夹**（`index.html`、`css`、`js`、`vendor`、`README.md`、`.nojekyll`）拖到仓库页面上传，然后提交。
3. 打开仓库的 **Settings → Pages**，Source 选 **"Deploy from a branch"**，分支选 `main`、目录选 `/(root)`，然后保存。
4. 大约 1 分钟后，网址就是 `https://你的用户名.github.io/nebula/`。别人点开就能用，不需要登录。

> 拖拽上传时，请把**解压后文件夹里面的内容**拖进去，不要拖外层文件夹本身，保证 `index.html` 在仓库根目录。
> `.nojekyll` 是隐藏文件。如果系统没显示出来，不传也没关系。

## 本地预览

浏览器出于安全原因，不能直接双击打开使用 ES 模块的网页，需要一个本地静态服务器（任选一种）：

```bash
python3 -m http.server 8000      # 然后打开 http://localhost:8000
npx serve .                      # 或者用 Node
```

麦克风输入需要在 **HTTPS** 或 **localhost** 下才能使用；GitHub Pages 默认就是 HTTPS。

## 展示模式

| 区域 | 功能 |
| --- | --- |
| 顶部 | 模式切换 A–F、「创作」进入工作室、场景预设、自动演示、随机生成、参数设置、全屏 |
| 左侧面板 | 10 个场景预设 + 6 种视觉模式 |

交互方式：拖动旋转、滚轮或双指缩放、点击空白处释放粒子、点击蝴蝶触发飞舞和爆发、移动鼠标或手指会推开或吸引粒子并留下光迹。

快捷键：`1–6` 切换模式 · `空格` 暂停 · `F` 全屏 · `R` 随机 · `D` 自动演示 · `S` 截图 · `H` 隐藏界面 · `T` 切换到创作模式

## 3D 创作工作室

点顶部的「创作」或按 `T` 进入。左侧工具栏共 7 个工具：

1. **蝴蝶**：颜色（冰蓝/紫/金/粉/红/绿/月白/彩虹，以及自定义取色）、8 种材质（柔光、水晶、玻璃、钻石、金属、霓虹、透明、全息）、发光强度、8 种翅膀纹理、5 种翅膀形状、尺寸、数量（1–33 只）、飞行速度、扇翅速度。
2. **粒子**：9 种形态（星尘、银河、光点、流星、能量碎片、光线丝带、烟雾、魔法光点、几何粒子），形态之间会平滑变换；还可以调数量、大小、速度、密度、颜色、透明度、发光、扩散范围、运动方向和流动强度，以及聚合/分散。
3. **轨迹**：开启绘制后，按住鼠标或手指在画面上画出路径，蝴蝶会沿路径飞行。可以画多条轨迹，每条可以是不同颜色。还可以调粗细、拖尾长度、立体纵深、速度，以及循环、往返、单次三种运动方式，也能撤销上一条、清除或重新播放。
4. **特效**：化为粒子、重新聚合、化作银河、发光水晶、能量光束、旋转星球、空间漩涡、发光花朵、群蝶汇聚、能量爆发。底部的特效栏可以一键触发。
5. **场景**：深空银河、梦幻星空、未来科技、水晶空间、粒子宇宙、霓虹空间、极光世界、无限光线隧道、魔法森林、纯黑极简。可以调背景颜色、环境亮度、雾效、光线和空间深度。
6. **视觉**：环境光、主光源、辉光、光线追踪风格、镜头远近/旋转/移动速度、自动环绕及速度、景深、动态模糊、曝光、饱和度。
7. **作品**：命名保存、打开、覆盖、重命名、删除、导出/导入 JSON 配置、导出 PNG、录制 WebM 视频、随机艺术、恢复默认。

作品和当前创作会**自动保存在本机浏览器**（localStorage）里，重新打开网页后会自动恢复，不需要账号。

快捷键：`Ctrl/⌘+Z` 撤销 · `Ctrl/⌘+Shift+Z` 或 `Ctrl+Y` 重做 · `1–7` 切换工具 · `B` 开关绘制 · `R` 随机 · `F` 全屏 · `T` 返回展示模式 · `Esc` 关闭面板

## 项目结构

```
index.html            页面结构 + importmap（three → vendor/）
css/style.css         玻璃拟态界面，桌面 / 平板 / 手机自适应
js/main.js            应用主循环、相机、模式过渡、各系统调度
js/config.js          模式、调色板、预设、默认参数
js/butterfly.js       程序化 3D 蝴蝶（翅膀网格、姿态、回声拖尾）
js/swarm.js           多只蝴蝶（Instanced 渲染、自由飞行与路径跟随）
js/particles.js       GPU 粒子场（全部运动在着色器里计算）+ 指针光迹
js/paths.js           自由绘制的 3D 飞行轨迹
js/environment.js     时空隧道、光束、中心光源、能量光环、深空背景
js/studioEnv.js       创作场景层：霓虹地面网格、水晶、发光森林、环境粒子
js/postfx.js          后期：体积光、Bloom、运动模糊、景深、色散、镜头光斑、暗角、颗粒
js/studio.js          创作工作室：配置、特效时间线、撤销/重做、作品存储
js/studioUI.js        创作工作室界面
js/ui.js              展示模式界面
js/audio.js           Web Audio 分析 + 内置合成音轨
js/capture.js         PNG 截图、MediaRecorder 录制
js/quality.js         设备分级与自适应画质
js/shaders/*.js       GLSL 着色器
vendor/three/         Three.js r181（MIT 许可）
```

## 兼容性与性能

- 需要支持 WebGL 2 的浏览器：近几年的 Chrome、Edge、Safari（iOS 15+）、Firefox 都可以。如果设备不支持，页面会显示提示，不会白屏。
- 打开时会根据设备自动选择画质档位。帧率不足时，先降低像素密度，再减少粒子数量。也可以在「画质」里手动固定档位。
- iPhone 的 Safari 不支持网页全屏 API，全屏按钮会改为进入沉浸模式（隐藏界面）。
